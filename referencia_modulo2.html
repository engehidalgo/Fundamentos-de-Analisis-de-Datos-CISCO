Las tres herramientas esenciales del analista de datos
Herramienta¿Qué es?¿Para qué sirve?Habilidades clave
Excel Hoja de cálculo con más de 1.2 mil millones de usuarios. Creada en 1985. Más de 450 funciones integradas. Pequeños datasets, análisis rápido, visualizaciones básicas, tablas dinámicas Limpieza de datos, fórmulas, gráficos, tablas dinámicas, formato condicional
SQL Structured Query Language — lenguaje de consulta estructurado para bases de datos relacionales Datasets grandes, bases de datos relacionales. Más rápido que Excel para grandes volúmenes Crear tablas, recuperar datos, consultas, combinaciones (JOINs)
Tableau Plataforma líder de análisis y visualización de datos. Conecta múltiples fuentes de datos. Dashboards interactivos, visualizaciones avanzadas para tomadores de decisiones no técnicos Dashboards, visualizaciones comparativas, conexión a Excel y SQL
Kaggle Comunidad en línea para científicos de datos y entusiastas del ML Obtener datasets públicos, competir, aprender, compartir proyectos Datasets CSV, notebooks, concursos, comunidad colaborativa

Estructura de una hoja de cálculo de Excel
ConceptoDetalle
FilasIdentificadas con números (1, 2, 3…). Total: 1,048,576 filas
ColumnasIdentificadas con letras (A, B, C…). Total: 16,384 columnas
CeldaIntersección de fila y columna. Se identifica como letra+número (A1, B2). Solo una celda está activa a la vez.
RangoConjunto de celdas. Formato: CeldaInicio:CeldaFin (A1:C5 selecciona desde A1 hasta C5)
Hoja de trabajoPestaña individual dentro del libro. Predeterminada: Hoja1
LibroArchivo Excel (.xlsx) que contiene una o más hojas de trabajo
Cuadro de NombreMuestra las coordenadas de la celda activa. Escribir coordenadas ahí navega a esa celda.

Importar archivos CSV a Excel
ConceptoDetalle
CSVComma Separated Values — valores separados por comas. Formato estándar para intercambio de datos.
DelimitadorCarácter que separa los campos. En CSV estándar es la coma (,).
Configuración regionalSi Windows usa separador distinto de coma, Excel puede cargar CSV incorrectamente. Solución: cambiar formato regional a "Inglés (Estados Unidos)"

Detalle de cada tipo de variable
TipoCategoríaDescripciónEjemplos
NominalCategóricaDos o más categorías sin orden implícito. El valor depende de la identidad del objeto.Sexo, color de ojos, tipo de animal, país
OrdinalCategóricaDos o más categorías donde el orden entre ellas es importante.Rango de clases (1ro, 2do, 3ro), escala de satisfacción, nivel educativo
ContinuaNuméricaPuede medirse a lo largo de un rango o secuencia. Puede tomar cualquier valor dentro del rango.Temperatura, tiempo, ingresos, volumen de ventas, peso, presión arterial
DiscretaNuméricaCuantitativa pero con un conjunto finito y específico de valores posibles.Número de sensores, cantidad de usuarios, número de automóviles, cantidad de visitas
Subtipos de variables continuas
SubtipoDescripciónEjemplo
De intervaloPuede tomar cualquier valor dentro del rango. El cero no significa ausencia total.Temperatura (0°C no significa "sin temperatura"), tiempo
De relaciónVariable de intervalo donde el cero SÍ significa ausencia total de esa variable.Ingresos ($0 = sin ingresos), volumen de ventas (0 = sin ventas)
¿Por qué importa el tipo de variable?
💡 El tipo de variable determina qué análisis y qué visualización aplicar. Las variables nominales se prestan a gráficos de barras. Las continuas permiten diagramas de dispersión. Las ordinales permiten análisis de rangos. Elegir la visualización incorrecta puede llevar a conclusiones erróneas.
Tipo de variableVisualizaciones sugeridas
NominalGráfico de barras, gráfico de torta (pocas categorías)
OrdinalGráfico de barras ordenado, mapa de calor
ContinuaDiagrama de dispersión, histograma, línea de tiempo
DiscretaGráfico de barras, gráfico de puntos
